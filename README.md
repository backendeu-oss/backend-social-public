# Backend Social

Private messaging and real-time community chat for Android and the web.

[Website](https://backendsocial.com) · [Google Play](https://play.google.com/store/apps/details?id=com.backend.social)

## What Backend Social offers

- Private conversations and public real-time rooms
- Replies, reactions, GIF support, and typing indicators
- A multilingual interface
- Privacy preferences, account controls, and active session management
- Optional two-factor authentication (2FA)

## Privacy and security

Backend Social is designed to minimize the collection of personal information. This repository is a public documentation hub only: it never contains production credentials, infrastructure details, admin endpoints, or user data.

For the current privacy information, read the policy available in the app and on the official website. Security reporting guidance is available in [SECURITY.md](SECURITY.md).

## Project status

Backend Social is actively maintained and available on Google Play. Product behavior and availability can evolve as the service improves.

## Feedback

For reproducible, non-sensitive product issues, open a GitHub issue. Never include private messages, passwords, recovery codes, authentication tokens, or personal data in a public issue.
